# 专业知识跨域转译框架：分析哲学表达

## 1. 总体定义

本框架是一种用于跨话语体系知识重述的、具有制度记忆、认知分工、公开证成、可撤销裁决与规范演化能力的人工认识制度。

它的核心问题不是多个 Agent 如何聊天，而是：命题内容如何保持，认识责任如何分配，理由如何获得公共可检验性，判断如何取得制度效力，以及行动规范如何随经验进行可控制的修订。

## 2. 主要概念映射

| 系统概念 | 分析哲学表达 |
|---|---|
| A 固态总体 | 历时持续的制度性认识主体 |
| B/C 液态 Agent | 短时存在的制度角色实例 |
| D 阶段总结 | 二阶规范反思与反思均衡机制 |
| 专业翻译 | 受约束的跨话语解释与概念重构 |
| 语义合同 | 命题内容、语义不变量和规范承诺集合 |
| 审核 | 基于公共理由的证成检验 |
| 通过 | 制度性接受，而非真值创造 |
| 返工 | 对未履行承诺的理由响应性修订 |
| 总库 | 历时性的完整事件档案 |
| 即时调用库 | 当前可行动的认识承诺集合 |
| 结晶 | 可回溯、可击败的抽象表征 |
| Skill | 程序性知识，即“知道怎样做” |
| 推理日志 | Agent 关于自身判断理由的显式言语行为 |
| 工作流 | 受构成性与规制性规则约束的行动程序 |

## 3. 翻译行为的形式对象

设：

- `S` 为源材料；
- `U` 为目标受众及其背景知识；
- `G` 为翻译的实践目的；
- `K` 为规范任务合同；
- `E` 为外部证据集合；
- `τ` 为 B 执行的转换函数；
- `O = τ(S,U,G,K)` 为候选输出。

系统不要求 `O` 与 `S` 在字面上同一，而要求它们在 K 所确定的范围内保持一组语义和推论不变量：

```text
I(K) = <P, R, Q, M, C, D, W>
```

其中：

- P：核心命题；
- R：推论结构和因果关系；
- Q：数量、单位和量化范围；
- M：可能、概率、必然等模态强度；
- C：前提、适用条件和范围；
- D：反例、异议与潜在击败条件；
- W：风险、警告和不可省略项。

表达方式可以变化，但不得无授权地改变指称、真值条件、因果方向、量化范围和模态强度。

## 4. 跨话语转译的哲学性质

本框架中的翻译是受约束的解释活动，兼具概念澄清、语义重述和说明性重构的性质。

B 可以改变概念的呈现方式，但原则上必须保持：

- 命题的真值条件；
- 核心概念的指称；
- 源材料允许和禁止的推论；
- 结论的认识强度；
- 有效的反例、例外和限定条件。

类比只是两个结构之间的局部映射，不是本体同一或完全等价。使用类比的 B 因而承担说明相似域与失效域的附加承诺。

跨领域解释通常具有翻译不确定性，同一组语义不变量可以由多个不同表述实现。Fresh-A、Fresh-B 和 Repair 三候选机制，是对这种多重可实现性和欠决定性的制度化处理。

## 5. A 的本体论地位

A 不是全知心灵，而是一个通过档案、规则、版本谱系、授权关系和裁决权保持历时同一性的制度主体。

A 的固态性并不表示其信念永不变化，而表示其认识史不能被静默重写：旧判断可以失效，旧记录不能被假装从未存在。

A 的裁决只改变命题或产物的制度地位：

```text
Accepted_A(p) 不蕴含 True(p)
```

A 批准某一命题，只意味着它在当前制度和证据条件下获得使用或交付资格，并不会使该命题因批准而变真。A 是可错、可修订且受规则限制的最终裁决者。

## 6. B、C、D 的角色本体论

B/C/D 首先是制度角色，而非必须具有持续人格同一性的心灵主体。

- B 是建设性的理由响应者，负责提出可能的知识表达。
- C 是批判性的理由检验者，负责寻找反例、违约和证成缺口。
- D 是元规范反思者，负责检验既有原则、判断和背景理论是否协调。
- A 是程序组织者、制度记忆承担者和最终裁决者。

必须区分角色类型与具体运行实例。长期存在的是角色规范、权限和程序性知识；单次 B/C 运行只是这些规范在特定任务中的临时实现。

## 7. 规范任务合同

规范任务合同不是普通提示词，而是一次跨话语知识重述能够成立所依赖的：

```text
命题内容
+ 语义不变量
+ 认识义务
+ 行动禁令
+ 许可范围
+ 验收条件
```

它同时提供：

1. 同一性标准：什么样的产物仍算在表达同一知识；
2. 正确性标准：什么样的表达才算充分履行本次任务义务。

合同中的规则分为：

- 构成性规则：决定某行为是否仍然算作该知识的转译。
- 规制性规则：规定已成立的转译行为应当如何做得更好。

把相关性改成因果性，会违反构成性规则；篇幅过长通常只违反规制性规则。构成性规则优先于风格、简洁和受众偏好。合同冻结后，事后新增硬条件构成一个新规范，而不是旧规范的追溯解释。

## 8. B1/B2：生成承诺

B1 是生成行为的基础规范，将合同转化为 B 必须承担的核心承诺：继续主张哪些命题、保留哪些限定、不得新增哪些断言、哪些简化仍保持语义同一，以及哪些类比会越过许可边界。

B2 是情境性实践义务空间，可加入受众、用途、媒介、篇幅、语气和术语要求。B2 可以决定 B 以什么方式履行义务，但无权决定不再履行某项核心义务。

B 的输出因此不是任意文本，而是对合同的一次履约尝试。每个事实陈述都携带相应的命题承诺；每次压缩、重排和类比都携带不产生误导性推论的附加责任。

## 9. C1/C2：满足条件

C1 是合同基础满足条件的集合，用于判断 B 是否保持命题、因果、数字、范围、风险和不确定性。

C2 是情境性验收规范，可以增加法规、格式、引用、文化、品牌和特殊风险要求，但不能降低 C1 的底线。

B1/C1 构成同一合同的规范对偶：

```text
合同条款
→ B 承担何种生成承诺
→ C 依据何种满足条件检验
→ 何种证据足以支持裁决
```

审核方法和陷阱样例可以隐藏，但足以导致失败的条件必须事先公开。没有生成义务对应的审核门槛缺乏追溯裁判的正当性；没有审核条件对应的合同要求则只是不可追责的空洞承诺。

## 10. 任务编译的规范性质

A 的任务编译不是拼接文本，而是把抽象规范实例化为角色相关、彼此一致的实践义务。编译器需要：

- 确定规则的适用范围、强度和来源；
- 区分构成性条件、硬性规制条件和软性偏好；
- 检查要求能否共同满足；
- 建立生成承诺与审核条件之间的映射；
- 冻结版本，使本轮的责任归属和裁决根据稳定。

两个硬要求不可共同满足，属于规范体系不一致，而不是 B 语言能力不足。B/C 无权自行折中，只能由 A 解释、排序、豁免或重订合同。

## 11. 社会认识论与认知分工

B/C 分离体现一种制度化的认知劳动分工。B 偏向生成、解释和受众适配；C 偏向反证、边界保护和风险识别。两者承担不同认识风险，因而需要不同的证据标准和信息权限。

C 的盲审具有认识论功能：减少锚定、意图辩护、声望偏见和对 B 自我解释的迎合。B 与 C 交换的不是私人心理状态，而是受到公共规范约束的证言：

```text
B 提交候选及可检查依据
C 提交裁决、证据和结构化缺陷
A 评估这些证言的相关性、独立性与可靠性
```

角色名称本身不产生认识权威。权威来自证据质量、可复核性、长期校准和错误发现能力。

## 12. 推理、原因与公开理由

系统必须区分三类对象：

1. 模型产生输出的内部因果计算；
2. Agent 对自己为何如此判断的自然语言说明；
3. 其他角色能够公开检查的正当化理由。

显式推理档案属于第二类，可能是近似说明、事后重构或错误自述。它不是对模型内部心智状态的无误访问。

执行轨迹说明系统事实上做过什么；公开理由说明为什么某项判断值得接受。A 可以保存所有显式推理，但裁决必须优先依据公开可检查的证据、规则、反例、命题映射和版本记录。

## 13. 三层记忆的认识论解释

- L0 是当前审议的工作记忆。
- L1 是面向行动的语义记忆，保存当前有效且尚未被击败的认识承诺。
- L2 是历时性的情景档案，保存系统曾接收、生成、审核、拒绝和决定过什么。
- Skill 是程序性记忆，保存此类任务应当怎样完成。

可以分别表述为：

```text
L2：过去发生过什么？
L1：目前哪些表征值得调用？
L0：本次审议正在使用什么？
Skill：此类任务应怎样做？
```

信息存在于档案中，不等于已被检索；被检索不等于已被理解；被理解也不等于足以证成结论。

## 14. 结晶的认识论地位

结晶是从原始事件产生的派生性抽象表征，本质上是一种有损压缩。每个结晶必须分别记录：

- 档案真实性：它是否确实来源于所标示的事件；
- 命题真值：它表达的世界状态是否成立；
- 认识地位：系统是否具有足够理由暂时接受它；
- 制度地位：A 是否已激活它供当前任务使用。

结晶可以替代活动上下文中的原文位置，但不能在本体上取代原始事件。它必须保留溯源、适用条件、反例、不确定性、置信度和潜在击败者。

没有回源关系的结晶只是不可核验摘要；能够回源的结晶才是可审计的认知抽象。

## 15. 总库的完整性命题

“总库绝对完整”可以表述为：对于系统边界内可观察且依法允许保存的每个事件，总库中都存在相应的事件记录。

这只是一项档案完整性命题，不蕴含：

- 总库包含世界上的所有真命题；
- 总库取得模型的全部内部状态；
- 总库中的所有内容都正确；
- A 在任何时刻实际掌握全部内容。

必须区分档案完整性、检索完整性、认知完整性和真值完整性。系统可以把第一项作为工程目标，不能由日志无限积累推出后三项。

## 16. 回源与可击败知识

系统中的认识承诺均具有可击败性。来源冲突、低置信度、事实异议、精确引用需求、来源撤回、版本变化和高风险决定，都会形成潜在击败者。

出现潜在击败者时，A 必须从结晶恢复原始记录和生成语境，重新审查证成链。回源不是异常补救，而是可修订知识制度的构成部分。

新版本可以撤销旧版本的当前效力，但不能抹除旧版本曾经存在或曾被采用的历史事实。版本谱系因此构成 A 历时认识身份的一部分。

## 17. C 的审核裁决

C 的审核可以形式化为：

```text
C(O,K,E) → <Verdict, Issues, Reasons, Confidence>
```

“不通过”不是审美偏好，而是关于 B 未充分履行某项合同承诺的规范判断。缺陷包必须说明违反了哪项承诺、证据在哪里、为何未满足条件、严重程度如何，以及修复时仍须保持哪些其他承诺。

当 B/C 对事实本身发生分歧时，继续改写不能解决真值问题。系统必须进入证据核验，不能用角色权威、语言说服力或候选数量代替证成。

## 18. 返工的哲学结构

Fresh-A 和 Fresh-B 是对同一规范问题的独立实现，用于探索翻译不确定性和多重可实现性。

Repair 是理由响应性修订：B 接受公开的反对理由，并尝试解除已经识别的违约状态。

复审必须分别回答：

- 候选是否独立满足当前合同；
- 旧缺陷是否真正解除；
- 修复是否引入新的违约；
- 三种实现之间是否存在实质认识优势。

相对最优不能代替绝对合格。三个错误答案中的最佳者仍然错误。

## 19. D 与反思均衡

D 是系统的二阶规范反思机制，在以下对象之间往返调整：

- 一般原则与 Skill；
- 具体任务中的通过、失败和返工判断；
- 关于受众、领域和审核可靠性的背景理论。

当个案反复与规则冲突时，D 不应自动假定规则正确或个案正确，而应考虑修订个案判断、一般规则或背景假设，以寻求反思均衡。

D 的阶段总结只是修订理由，不具有自动改变规范的制度效力。其提案必须接受独立保留集、反例、高风险案例和历史回归测试，并经 A 正式批准。

## 20. Skill 的认识论类别

Skill 属于程序性知识，即“知道怎样做”，而不是命题性知识，即“知道某件事为真”。

知识库保存事实、来源、领域命题和术语关系；Skill 保存如何构造合同、如何重述概念、如何识别类比越界、如何审核、何时返工以及何时升级人工。

Skill 的认识论价值取决于它能否在明确适用范围内稳定改善结果，而不是其文本是否具有说服力。系统不能以自身产生的数据、规则和评分循环证明自身正确，因而 Skill 更新必须使用独立评测、反例、回归、灰度和回滚机制。

## 21. A 的接受条件

A 只有在下列条件均满足时才有充分理由接受候选：

1. 所有构成性语义条件均满足；
2. 不存在尚未解除的严重认识击败者；
3. C 的证成质量和置信度达到风险阈值；
4. 候选不存在无来源的重要新增承诺；
5. 实践适切性达到目标受众标准；
6. 高风险任务已经完成所需的外部专家复核。

A 的裁决必须可追溯、可重开、可撤销。最终权威并不意味着不可错误。

## 22. 质量标准的哲学表达

系统质量由以下维度组成：

- 真值条件忠实性：是否保持核心命题的真假条件；
- 指称忠实性：概念是否仍然指向正确对象；
- 推论忠实性：读者是否会作出源材料不允许的推论；
- 模态忠实性：可能、概率和确定性是否保持；
- 证据忠实性：断言强度是否超过证据；
- 语用适切性：表达是否适合目标受众和用途；
- 认知可获得性：目标读者能否形成预期理解；
- 规范合规性：是否履行合同和安全义务。

“真正易懂”是关于目标受众实际表现的经验命题，不能仅由 B/C 自我判断确立，最终需要理解测试或用户研究支持。

## 23. 停止条件的认识论意义

自动返工必须是有界程序。达到资源上限、连续修订无认识增益、严重错误反复出现、来源证据不足、C 判断不稳定或所有候选均无法满足构成性条件时，系统应停止自动处理。

此时合理的制度状态不是强行选择，而是承认：

```text
系统目前没有充分理由交付任何候选。
```

承认证成不足是可靠认识制度的一部分，而不是系统失败的掩饰。

## 24. 总体哲学定式

A 是通过记录、规则和裁决权保持历时同一性的制度性认识主体；B 承担跨话语重述中的生成承诺；C 依据公共满足条件检验这些承诺是否履行；D 在个案、一般规范与背景理论之间寻求反思均衡。

总库保存完整的制度认识史，即系统曾经接收什么、主张什么、依据什么和决定什么；即时调用库保存系统当前仍愿意承担的可行动认识承诺；Skill 保存经过验证的程序性能力。

A 的接受赋予产物制度效力，却不创造真理。整个系统的合理性来自公共理由、证据谱系、角色独立、认识可击败性、裁决可修订性，以及对自身规范和历史决定保持持续反思。
